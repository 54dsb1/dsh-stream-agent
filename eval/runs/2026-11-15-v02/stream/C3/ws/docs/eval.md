
# 评估计划摘要

## 指标（METRICS）

METRICS 由四组构成：任务完成率、首次通过率、每任务平均命令数、以及单位任务 token 消耗。前两项衡量正确性，后两项衡量协议纪律与上下文效率。所有 METRICS 均在冻结的 fixture 工作区上采集，避免环境漂移。

## 基线（baseline）

baseline 采用原生多轮工具调用代理：每条工具结果都回灌上下文，逐轮推进。对照组的区别在于本协议把结果句柄化，按需 peek，因此命令数与 token 曲线应呈现更平的斜率。baseline 与实验组共用同一批 manifest 任务，逐条比对状态与产物哈希。

## 判定方式

任务视为通过需同时满足：四份产物按说明生成、报告文件逐个列出状态、且无协议级错误注入。任一条件不满足则记录失败原因并计入分母。
