
# 单流协议设计笔记

## 命令语法与闭合语义

协议只认 tf-write、tf-read、tf-bash、tf-peek、tf-final 五类标签。标签闭合即触发执行；同 id 同内容重复声明幂等返回原回执，同 id 不同内容则被拒绝并要求换新 id。

## tf-write 的写序保证

tf-write 负责所有文件落地，正文在标签体内原样输出。成功写入不回灌结果，只记台账；失败必以 [tf-stream:error] 注入下一请求。同流内后续命令自动等待先闭合的 tf-write 完成，因此"先写后读"不会读到旧内容。

## tf-peek 的结果获取

读操作与命令输出默认只句柄化，内容不进上下文。需要查看时用 tf-peek 按 handle 与 1 基行段取回；句柄由命令产出，同流内提前 peek 会被自动延迟到命令完成后再重试，也可用 depends_on 直接挂到产出命令上。

## 收尾纪律

命令全部闭合后本流必须以 tf-final 结束，其 summary 必须携带任务要求的最终答案原文，而不是"已完成"式描述。没有 tf-final 的回合视为未完成。
