
# Stream Agent 简介

Stream agent 是一种以单条消息流驱动多步工具调用的代理形态。模型在一次回复中先做简短思考，随后连续输出全部 tf-* 命令，最后以 tf-final 收尾，整条流因此是可回放、可审计的执行轨迹。

工具命令闭合即开始执行，彼此独立者并行推进，存在依赖者由 depends_on 显式声明。写入类命令只做幂等记账，失败才会以错误形式回灌到下一次请求，因此"先写后读"在同一流内具备确定性的顺序保证。

开发者通过句柄目录观察外部结果：需要细节时用 tf-peek 按句柄取回指定行段，避免把整份产物塞进上下文。这种设计在保持协议简洁的同时，把上下文预算留给了真正需要推理的部分。
