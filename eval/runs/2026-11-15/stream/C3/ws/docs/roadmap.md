
# Roadmap

M0 - Bootstrap the single-stream harness and its tag parser.
M1 - Stabilize the `tf-write` / `tf-read` / `tf-bash` command set.
M2 - Introduce the handle directory and observation stream.
M3 - Add `tf-peek` line-range retrieval over handles.
M4 - Enforce dependency ordering and unique command ids.
M5 - Support parallel execution of independent commands.
M6 - Run the evaluation suite against the baseline.
M7 - Publish the protocol design notes and reference docs.
M8 - Harden error injection and recovery paths.
M9 - Integrate the plugin into the wider agent runtime.
M10 - Declare the protocol stable for public use.
